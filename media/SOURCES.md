# Screenshot provenance

Environment: Agent Studio 1.13.3, official DSH 0.2.0-rc.2, an isolated data directory, no navigation/theme/Library plugins. The model is a local scripted verification adapter; all Agent names, instructions, messages and edited results are synthetic demonstration data. Images are unmodified browser screenshots, not generated interface mockups.
